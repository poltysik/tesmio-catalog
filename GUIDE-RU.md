# Tesmio Catalog — инструкция

Tesmio Catalog добавляет слева в нижнее меню строительства отдельную общую вкладку
для строений, которые работают через TesmioLoader. Она находится перед
автодорогами на нейтральной панели и не относится к транспортной отрасли.

## Установка

1. Установить совместимый TesmioLoader и запускать игру через
   `tesmiolauncher.exe`.
2. Скопировать содержимое папки `plugins` из архива в
   `SovietRepublic\tesmioloader\build\plugins`.
3. Скопировать папку `vfs` из архива в `SovietRepublic\tesmioloader\vfs` с
   объединением папок. Важно: это VFS рядом с папкой `build`, а не внутри неё.
4. Полностью перезапустить игру через TesmioLauncher.

## Возможности и автоматическое распознавание

- Фильтрация по типу, ресурсу и источнику постройки.
- Дополнительные фильтры «Потребляет» и «Производит» для выбранного ресурса.
- Отдельные источники: базовая игра, Мастерская Steam и Tesmio.
- Избранное, режим «Только доступные» и штатные ограничения игры.
- Автоматический выбор русского или английского интерфейса по языку игры.
- Автоматическое обнаружение новых ресурсов и совместимых строений.

Если подписка Workshop содержит папку `plugins` с файлами для ручной установки
в TesmioLoader, её строения автоматически относятся к источнику Tesmio. Вносить
Steam ID или внутреннее имя здания в `tesmiomenu.ini` не требуется.

## Совместимость

Текущая сборка рассчитана только на WRSR 1.1.1.7 и TesmioLoader API 3/b0.3.4.
Она не меняет `SOVIET64.exe` на диске. Перед установкой перехватов DLL проверяет
известные байты функций; после несовместимого обновления плагин должен отключить
себя и записать `unsupported game build` в лог.

Сама вкладка в сохранение не записывается. Однако здания и новые ресурсы из
других модов могут быть частью сохранения, поэтому их нельзя отключать перед
загрузкой такой республики.
